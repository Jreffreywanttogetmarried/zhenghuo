```

```

下表路径相对该技能目录。素材库的约定：

- 免费使用、免费转发；

- 不同来源保留各自许可，整个合集不能简单标成全部 MIT；
- 电影、艺术风格与示例名称只是参考描述，不代表官方合作或背书。

- 画面由代码绘制，不是 AI 生成的实拍影像。
