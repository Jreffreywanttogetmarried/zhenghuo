# 04 · 视觉规范

> 这份规范把教程里的「通用制作规范」翻译成了本项目的引擎参数。改视觉先改 `engine/palettes.js` 和 `engine/components.js`，不要在每一期里散落颜色和字号。

## 1. 输出规格

| 项目 | 值 |
|---|---|
| 画幅 | 1920 × 1080（横屏） |
| 帧率 | 30 fps |
| 编码 | H.264 |
| 像素格式 | yuv420p |
| 码率 | ≥ 12 Mbps（渲染器默认 14M CBR，实际约 12.6 Mbps；也可用 `--crf`） |
| 音频 | 默认无声；有音轨时 AAC 192kbps |
| 字幕 | 烧录在画面里；另导出 SRT 备份 |

> 如果要做竖屏 1080×1920，不是把横屏裁一下：字幕位置、图表宽度、主体构图都要重新排。竖屏版本应作为独立的 layout 分支。

## 2. 安全区

```
1920 × 1080
┌──────────────────────────────────────────────┐
│ 96                                          │
│    ┌────────────────────────────────────┐    │
│    │                                    │    │
│    │        主画面 / 主体                 │    │
│    │                                    │    │
│    └────────────────────────────────────┘    │
│         字幕区（距顶约 690，最多两行）         │
│                                              │
│  底部信息条（距底约 40–78）                    │
└──────────────────────────────────────────────┘
```

- 左右安全边距：120px（字幕最大宽度 1640px）。
- 顶部角标：x=120, y=92。
- 字幕默认 top=690；主体在下方时移到 top=110。
- 底部信息条：线在 `height-78`，文字在 `height-48`，24px。
- 不要让字幕压住图表、人物脸、关键数字。

## 3. 字体

| 用途 | 字体 | 字重 | 字号 | 备注 |
|---|---|---|---|---|
| 普通字幕 | Noto Sans SC | 700 | 64px | 字间距 2px，最多两行 |
| 关键词 | Noto Sans SC | 800 | 64px | 金色 `#FFC15E` |
| 金句/名词卡 | Noto Serif SC | 900 | 96–150px | 暖白 `#FFF3DC`，外发光 |
| 数字 | Noto Sans SC / Noto Serif SC | 800–900 | 80–150px | 等宽数字感 |
| 角标/注释 | Noto Sans SC | 500–600 | 22–30px | 低对比 |
| 图表标签 | Noto Sans SC | 400–600 | 19–24px | 不与字幕抢 |

- 字体文件在 `assets/fonts/`，通过 `engine/base.css` 的 `@font-face` 加载。
- 中文**不要**用 three.js 的 3D 文字几何体，会显示成方块；中文一律在 Canvas/DOM 层渲染。
- 标题卡进场：1.1 倍缩到 1.0 倍；金句外发光 `0 0 40px rgba(255,170,70,0.55)`。

## 4. 三套颜色预设

| 变量 | 科学 `science` | 历史 `history` | 投资 `investing` |
|---|---|---|---|
| 背景 0 | `#02040A` | `#120E0A` | `#07110D` |
| 背景 1 | `#07182A` | `#2A1C10` | `#10231B` |
| 文字 | `#F4F7FB` | `#F2E7D3` | `#F3EFE3` |
| 弱化 | `#8FA3B8` | `#B09A7A` | `#93A89A` |
| 主强调 | `#FFC15E` 金 | `#D8A84E` 旧金 | `#E0B15C` 金 |
| 副强调 | `#7FD0FF` 冷青 | `#9B4A32` 铁锈红 | `#D35F4A` 红 / `#5B8FD6` 蓝 |
| 纸/卡 | `#0B1B2A` | `#E8D6B3` | `#F4EBDD` |
| 纸上墨色 | `#F4F7FB` | `#2B2118` | `#1F2933` |

- 字幕在深色背景用白色 + 黑色双层阴影；在浅色纸卡上，字幕仍然放在深色舞台区，不要直接压在纸卡上。
- 一个画面只留一个主强调色。金色用于「光、关键词、关键数字」，红色用于「警告、亏损、反转」，蓝色用于「数据、冷静」。
- 不要同时用三种以上高饱和色。

## 5. 字幕组件

`engine/components.js` 的 `drawSubtitle` 已经实现：

- 64px / 700；关键词 800；
- 白色 `#FFFFFF`，关键词 `#FFC15E`；
- 字间距 2px；
- 双层阴影：`blur 30 / offset 0` + `blur 8 / offsetY 2`；
- 7 帧淡入 + 从下往上 12px；7 帧淡出；
- 默认 top=690，`position: "top"` 时 top=110；
- 最多两行；超过两行会在控制台警告。

用法（`episode.json`）：

```json
{
  "start": 0.4,
  "end": 3.2,
  "text": "你在上海，给朋友发了一张【照片】",
  "position": "bottom"
}
```

## 6. 标题卡 / 金句 / 数字

### 标题卡

- 宋体 900，96–150px，暖白 `#FFF3DC`，金色关键词。
- 进场：1.1 → 1.0，0.35 秒；出场 0.3 秒。
- 适合：片名、名词卡、章节卡、结尾金句。
- `episode.json` 的 `titles` 数组，或在场景里直接绘制。

### 数字

- 从 0 滚到目标值，20–40 帧（0.67–1.33 秒）。
- 停下时轻微放大回弹（引擎已实现 5.5% 的 bump）。
- 大数字用 80–150px；旁边配一行 24–30px 的说明。
- 数字格式：千分位逗号；单位用半角空格隔开（`299,792,458 m/s`）。

### 信息条

- 底部常驻，24px，弱化色；右侧可用强调色。
- 适合：计时器、里程、价格、进度、对比。
- 不要和信息条抢字幕区；信息条在 `height-78` 以下。

## 7. 图表与数据

- 图表本身就是叙事，不是装饰：每一根柱子、每一条线都要有数据含义。
- 数据必须真实、可追溯；图表旁边或 `sources.md` 里写来源。
- 柱子从 0 生长，20–40 帧；最后一项用强调色。
- 折线在柱子之后出现，用平滑曲线；关键点加小圆点。
- 坐标轴标签 19–24px；不要和字幕同字号。
- 投资类：红/蓝铅笔色（`#D35F4A` / `#5B8FD6`）画在奶油纸卡上；纸卡外是深色舞台。
- 历史类：时间轴节点用旧金 + 羊皮纸；节点标签上下交替，避免重叠。
- 科学类：深色背景 + 金色光迹 + 冷青辅助；公式和图形用「变形/推导」而不是 PPT 式切页。

## 8. 运动

- 所有镜头运动由 `t` 计算，用 `easeInOutCubic` / `easeOutCubic`；不要匀速、不要抖。
- 一个镜头只讲一件事；镜头运动要服务内容。
- 物体出现：优先「运动到位」（从画外飞入、生长、展开），少用纯 alpha 淡入。
- 数字/图表：生长 + 回弹；不要随机抖动。
- 转场：穿过、变形、遮挡、匹配剪辑；少用黑场淡入淡出。

## 9. 3D 场景（可选）

需要 Three.js 时：

- 项目已本地化 Three.js r187：`engine/vendor/three/`（MIT）。参考实现见 `episodes/000-3d-test/`。
- 场景模块自己创建离屏 WebGL renderer，`renderer.render()` 后把 canvas `drawImage` 到引擎的 2D canvas；字幕/标题仍由 2D 层绘制。
- 材质：`MeshPhysicalMaterial`，clearcoat + 柔和高光；玻璃用 transmission 0.9 / ior 1.46。
- 阴影：`PCFSoftShadowMap`；主体加轮廓光（rim light）。
- 发光：Bloom 强度 0.6–1.2，阈值 0.8；加轻微暗角。
- 抗锯齿：MSAA 或 `--scale=1.5` 渲染再缩到 1080p。
- 粒子：上万粒子用 `InstancedMesh` 或 `Points`，不要一个一个 Mesh。
- 地球/地图：用真实海陆轮廓数据（Natural Earth GeoJSON），不要画色块。
- 中文：不要用 three.js 自带字体；中文放 Canvas/DOM 层。

## 10. 确定性

- 禁止 `Math.random()`、`setTimeout`、`requestAnimationFrame` 驱动画面。
- 需要随机：用固定种子（`engine/math.js` 的 `seeded`）。
- 所有异步资源（字体、图片、纹理）必须在 `renderAt` 返回前加载完。
- 同一时间重复渲染，像素结果必须一致。

## 11. 性能

- 1080p / 30fps 逐帧截图较慢；先渲 5–10 秒检查，再渲全片。
- 长片分段渲染（每段几百帧），失败不用从头再来。
- 大量粒子用 `InstancedMesh`/`Points`；避免每帧创建新 Canvas/渐变对象。
- 字体加载一次，缓存；不要在每帧 `document.fonts.load`。

## 12. 不要做

- 不要从黑场淡入开场。
- 不要让画面静止超过 3 秒。
- 不要用 AI 生成真实人物的脸。
- 不要把中文放进 3D 文字几何体。
- 不要用未经授权的音乐/图片/字体。
- 不要把无配音预览说成「已配音成片」。
- 不要用随机数、计时器驱动画面。
