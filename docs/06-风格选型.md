# 06 · 风格选型

> 341 种风格不是「越多越好」。正确做法：**1 个主画风 + 1 个运动语法 + 1 个版式/数据风格**，各司其职。
> 把多个风格的全部约束机械叠加，画面会变成四不像。

## 3. 三个方向的默认配方

### 历史：档案纸 + 时间轴

| 职责 | 推荐编号 | 名称 | 静帧 | 为什么 |
|---|---|---|---|---|
| 运动 | **M20** | 时间线/历史 | 无（文字参考） | 时间轴推进、节点放大再缩回，天然适合因果链 |
| 主画风 | **K35** | 旧学院风 | 无（文字参考） | 泛黄、棕褐、老书；给「档案感」定调 |
| 主画风备选 | **L16** | 档案灯箱 | 有 | 真实档案物件放在灯箱上，放大镜进入；有静帧可参考 |
| 版式 | **L5** | 视觉调查 | 有 | 照片、文件、证言排在同一条时间轴，适合「来龙去脉」 |
| 备选画风 | **O69** | 英国病人 | 有 | 琥珀褐水彩、地图、便条、压花；适合感情线 |

**视觉母题**：羊皮纸、旧地图、罗盘、档案照片、手写标注、时间轴节点。
**不要**：现代霓虹、赛博朋克、过度 3D 金属感。

### 科学：深色实验室 + 原理拆解

| 职责 | 推荐编号 | 名称 | 静帧 | 为什么 |
|---|---|---|---|---|
| 运动 | **M21** | 原理拆解（它是怎么工作的） | 无（文字参考） | 把过程拆成 3–5 步，前一步结果变成下一步开头 |
| 运动备选 | **M18** | 数学/科学讲解（3Blue1Brown 那种） | 无（文字参考） | 公式和图形一点点变形、推导；适合抽象原理 |
| 主画风 | **E1** | 极简几何 | 有 | 圆、方、半圆在纯色上滚动/生长；干净、可读 |
| 主画风备选 | **L41** | 等距信息图 | 有 | 剖面、拆解、流程、尺度变化；适合「它怎么工作」 |
| 粒子/能量 | **B3** | 粒子聚形 | 有 | 粒子聚成形状再散开；适合光、能量、抽象概念 |
| 数据 | **F1** | 图表生长 | 有 | 柱子生长、数字跳动、连成线；适合数据和结论 |

**视觉母题**：深蓝黑背景、金色光迹、冷青玻璃、轨道、剖面、粒子、公式变形、尺度对比。
**不要**：PPT 式切页、纯文字讲解、过度花哨的转场。

> M18 的原始提示词提到 Manim；我们借用它的「推导/变形」语法，用本项目的 Canvas 引擎实现，不强制安装 Manim。

### 投资：奶油纸卡 + 数据叙事

| 职责 | 推荐编号 | 名称 | 静帧 | 为什么 |
|---|---|---|---|---|
| 运动/叙事 | **L40** | 数据叙事 | 有 | 图表本身就是故事；红蓝铅笔逐笔画出，手写注释钉在数字上 |
| 数据 | **F1** | 图表生长 | 有 | 柱子生长、数字跳动、连成线；和纸卡天然搭 |
| 版式 | **H12** | Editorial Forest | 无（文字参考） | 绿、粉、奶油杂志配色，衬线标题，细线 |
| 版式备选 | **L10** | 工程方案比较墙 | 有 | 多个方案放在一面墙上逐个受检；适合对比 |
| 节奏 | **M7** | 极简卡点 | 无（文字参考） | 一个镜头只讲一件事，大量留白，一个强调色 |

## 4. 怎么读一条风格提示词

每条 `.md` 通常是：

```
# 编号 名称
- 分类
- 长什么样
- 适合

## 风格提示词
（一段可以直接粘给模型的话，可能含 {{ }}）

## 补充
### 参考
### 配合 skill
```

使用步骤：

1. 先看「长什么样 / 适合」，判断是否匹配；
2. 读「风格提示词」，把 `{{ }}` 换成你的内容、时长、画幅；
3. 保留形成该风格的核心视觉特征（颜色、材质、运动方式、版式），不要只抄字面；
4. 把它翻译成本项目的参数：
   - 颜色 → `engine/palettes.js` 或场景内局部色；
   - 字体 → `engine/base.css`；
   - 运动 → 场景里的 `t` 曲线；
   - 版式 → 组件参数；
5. 在 `episode.json` 的 `styleRefs` 里记录编号和名称。

- 341 条中约 196 条有静帧；其余是文字参考。

## 7. 记录格式

在 `episode.json`：

```json
"styleRefs": {
  "motion": "M20 时间线/历史",
  "art": "K35 旧学院风",
  "layout": "L5 视觉调查",
  "references": [
    "assets/library/风格提示词/M_动态风格/M20_时间线·历史.md",
    "assets/library/风格提示词/K_卡通画风/K35_旧学院风.md"
  ]
}
```

在 `notes.md` 里再写一句：**为什么选它、不选什么**。这比编号本身更有用。

## 8. 选型自检

- [ ] 主画风只有一个，不是三个风格的平均值
- [ ] 运动语法服务于内容，不是「为了动而动」
- [ ] 版式/数据风格不和主画风打架
- [ ] 颜色不超过 1 个主强调 + 1 个副强调
- [ ] 有静帧参考的，看过静帧；没有的，明确是文字参考
- [ ] 记录在 `styleRefs` 和 `notes.md`
