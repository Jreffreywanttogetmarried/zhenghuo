# 01 · 制作流程

> 目标：用「代码动画」做 2–3 分钟横屏科普视频。画面由 HTML/Canvas 逐帧绘制，`window.renderAt(t)` 是唯一时间接口，FFmpeg 编码成 MP4。
> 这套流程结合了两份材料：本地教程 `references/AI视频副业攻略.pdf` 的制作规范，以及 `code-animation-prompts` 技能的 341 种风格提示词。

## 0. 一张图看全流程

```
选题评估 → 大纲 → 分镜表 → 事实核查 → 风格选型 → 15 秒样片 → 全片制作 → 质检 → 发布包
   ↑         ↑        ↑          ↑           ↑           ↑           ↑         ↑
 评分≥75   五幕结构  时间码     sources.md   3 个编号    6 张截图    分段渲染   清单     mp4/srt
```

每一关都有「不过不往下走」的硬条件。最贵的错误不是代码写错，而是选题/结构错了以后返工整条。

## 1. 选题（0.5–2 小时）

产出：`templates/选题评估表.md` 填好的评分表。

- 三个方向：历史、科学、投资。
- 好选题的三个硬条件：
  1. **3 秒内能说清的反常识钩子**（问题或具体数字）；
  2. **有一个能贯穿全片的视觉主角**（一束光、一张纸、一枚硬币、一条线、一个二维码……）；
  3. **关键数字能在 30 分钟内找到可靠来源**。
- 评分 ≥ 75 才进入大纲；任何一项 ≤ 2 分先解决。
- 选题库见 `docs/02-选题与大纲.md`，里面的候选都还没核查，使用前必须自己查证。

## 2. 大纲（1–2 小时）

产出：`episodes/<slug>/outline.md`。

必须写清楚：

- 一句话 logline；
- 核心反常识点；
- 全片视觉主角；
- 五幕结构（问题 → 进入 → 原理 → 人的故事 → 回收/升华）；
- 观众看完能转述的一句话；
- 视觉化清单：每个抽象概念对应什么画面；
- 事实核查清单。

## 3. 分镜表（1–3 小时）

产出：`episodes/<slug>/storyboard.md`，以及同步的 `episode.json` 时间轴。

规则：

- 字幕按 **每秒 6–7 个字** 写；单句停留 **2–3 秒**；最多两行。
- 每一句字幕都必须对应一个看得见的画面变化；不能「字在换、画面不动」超过 3 秒。
- 镜头永远在缓慢运动（推、拉、摇、环绕），用 easeInOut，不匀速、不抖。
- 开头 3 秒内出现钩子；第 1 帧画面完整，不从黑场淡入。
- 场景之间优先「镜头穿过去 / 物体变形」，少用淡入淡出黑场。

## 4. 事实核查（0.5–2 小时，和分镜并行）

产出：`episodes/<slug>/sources.md`。

- 所有数字、年份、人名、引语，写进画面之前必须登记来源。
- 不确定的数字用保守说法：「约」「超过」「几十」。
- 真实人物只用可商用授权照片；找不到就用剪影，**不要用 AI 生成真人的脸**。
- 涉及除法、百分比、复利、单位换算的，用代码算一遍再写进画面。

## 5. 风格选型（0.5–1 小时）

产出：`episode.json` 里的 `styleRefs`，以及 `notes.md` 里的风格决定。

- 从 `code-animation-prompts` 素材库选 **1 个主画风 + 1 个运动语法 + 1 个版式/数据风格**。
- 不要机械叠加多个风格的全部约束；每个风格只负责一个职责。
- 三种 default 配方见 `docs/06-风格选型.md`。
- 打开技能目录下的 `assets/library/风格挑选.html` 看静帧；命令行检索用：
  ```bash
  python ".claude/skills/code-animation-prompts/scripts/styles.py" search 时间线
  python ".claude/skills/code-animation-prompts/scripts/styles.py" show M20
  ```

## 6. 15 秒样片（0.5–1 天）

产出：`episodes/<slug>/output/sample-15s.mp4` + 6 张关键帧截图。

- 先做开头 15 秒，验证：钩子、字体、字幕可读性、主体运动、颜色。
- 截图命令：
  ```bash
  python tools/snapshot.py episodes/<slug> --times 0,3,6,9,12,14
  ```
- 样片确认后再做整条。每次只改一两个地方，改完看截图，比看整条快。

## 7. 全片制作（1–2 天）

产出：`episodes/<slug>/` 下的场景模块与 `output/<slug>.mp4`。

- 场景拆成多个文件：`scenes/01-hook.js`、`scenes/02-...js`，每个场景一个文件。
- 时间轴统一写在 `episode.json` 的 `scenes` 里（start/duration），方便改节奏。
- 长片分段渲染，每段几百帧，再用 FFmpeg 拼接；中途出错不用从头再来。
  ```bash
  python tools/render_video.py episodes/<slug> --start 0 --end 40 --output episodes/<slug>/output/part1.mp4
  python tools/render_video.py episodes/<slug> --start 40 --end 80 --output episodes/<slug>/output/part2.mp4
  python tools/stitch.py episodes/<slug>/output/part1.mp4 episodes/<slug>/output/part2.mp4 \
    --output episodes/<slug>/output/<slug>.mp4
  ```

## 8. 质检（0.5–1 小时）

产出：填好的 `docs/07-质检清单.md`。

- 每 4 秒截一张总览图，检查有没有黑帧、字幕被挡、画面不动、数字不一致。
- 用 `ffprobe` 检查分辨率、时长、帧率、像素格式、音轨。
- 同一时间重复渲染两次，确认画面一致。

## 9. 发布包（0.5 小时）

产出：`templates/发布包.md` 填好的内容 + 成片 + SRT + 封面。

- 成片：1920×1080 / 30fps / H.264 / yuv420p / ≥12 Mbps。
- 字幕：`python tools/export_srt.py episodes/<slug>`。
- 来源、音乐、字体许可、AI 生成声明写进简介或置顶评论。

## 时间预期

| 阶段 | 第一次 | 熟练后 |
|---|---|---|
| 选题 + 大纲 | 2–4 小时 | 1 小时 |
| 分镜 + 事实核查 | 2–5 小时 | 1–2 小时 |
| 15 秒样片 | 0.5–1 天 | 2–3 小时 |
| 全片 | 1–2 天 | 半天 |
| 渲染（2 分钟片） | 20–40 分钟（有独显） | 同左 |

> 数据来自教程 `references/AI视频副业攻略.pdf` 的常见问题部分，实际取决于机器和修改次数。

## 文件对应关系

| 文件 | 作用 |
|---|---|
| `episode.json` | 期数元数据、场景时间轴、字幕、palette、风格编号 |
| `scenes/*.js` | 每个场景的绘制代码，只依赖 `t` 与 `env` |
| `outline.md` | 大纲 |
| `storyboard.md` | 分镜表 |
| `sources.md` | 事实与素材来源 |
| `notes.md` | 制作笔记、修改记录 |
| `output/` | 样片、成片、截图、SRT |
