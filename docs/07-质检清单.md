# 07 · 质检清单

> 出片前至少完整过一遍。先在 5 秒/10 秒小段上检查，再渲全片；不要等 2 分钟渲完才发现字幕被挡。

## 1. 前期闸门

- [ ] 选题评分 ≥ 75（`templates/选题评估表.md`）
- [ ] 大纲写清楚 logline / 视觉主角 / 五幕 / 结尾金句
- [ ] 分镜表每镜有画面、镜头、字幕、转场
- [ ] `sources.md` 覆盖所有数字、年份、人名、引语
- [ ] `styleRefs` 记录了主画风/运动/版式编号
- [ ] 15 秒样片已确认（6 张关键帧截图）

## 2. 画面

### 首帧 / 中段 / 尾帧

```bash
python tools/snapshot.py episodes/<slug> --times 0,5,15,30,60,90,120
```

- [ ] 第 1 帧画面完整，不是黑场/纯色/未加载
- [ ] 首帧 3 秒内有钩子
- [ ] 中段没有黑帧、闪白、穿模
- [ ] 尾帧不是突然截断；最后一句字幕完整停留
- [ ] 每个场景切换有明确视觉理由
- [ ] 没有超过 3 秒的静止画面
- [ ] 没有字幕被主体挡住、出画、重叠
- [ ] 字体没有溢出画面/被裁切
- [ ] 中文没有显示成方块/乱码
- [ ] 关键数字与字幕稿一致

### 总览图

```bash
python tools/snapshot.py episodes/<slug> --every 4
```

把截图按顺序看一遍，检查：

- [ ] 节奏是否有起伏（不是每 4 秒都一个样）
- [ ] 是否有「字在换、画面不动」的段落
- [ ] 颜色是否统一，没有突然出现不协调的高饱和色
- [ ] 图表/时间轴/数字是否清晰可读

## 3. 字体与字幕

- [ ] Noto Sans SC / Noto Serif SC 实际加载（不是系统回退字体）
- [ ] 普通字幕 64px，关键词金色 `#FFC15E`
- [ ] 字幕最多两行；没有超长句
- [ ] 字幕速度 6–7 字/秒；单句 2–3 秒
- [ ] 字幕在深色背景可读，在浅色纸卡上没有直接压字
- [ ] 主体在下方时，字幕已移到上方（top=110）
- [ ] 标题卡/金句没有和字幕重叠

## 4. 确定性

- [ ] 同一 `t` 渲染两次，截图哈希一致
- [ ] 没有 `Math.random()`、`setTimeout`、`requestAnimationFrame` 驱动画面
- [ ] 随机粒子/纹理使用固定种子
- [ ] 字体/图片/纹理在 `renderAt` 返回前加载完
- [ ] 同一段重新渲染，画面不闪、不跳

快速检查：

```bash
python tools/snapshot.py episodes/<slug> --times 7.5 --out-dir output/check-a
python tools/snapshot.py episodes/<slug> --times 7.5 --out-dir output/check-b
# 比较两张 PNG 的哈希
```

## 5. 技术规格

```bash
python tools/verify_video.py episodes/<slug>/output/<slug>.mp4 --duration 120
# 或手动
ffprobe -v error -show_entries stream=codec_name,width,height,r_frame_rate,pix_fmt \
  -show_entries format=duration,bit_rate -of default=noprint_wrappers=1 episodes/<slug>/output/<slug>.mp4
```

- [ ] H.264
- [ ] 1920×1080（或目标分辨率）
- [ ] 30fps
- [ ] yuv420p
- [ ] 时长与分镜表一致（误差 < 1 帧）
- [ ] 码率 ≥ 12 Mbps
- [ ] 有音轨时：AAC，能正常播放
- [ ] 文件能从头播到尾，不卡顿

## 6. 事实与合规

- [ ] `sources.md` 每条数字都能点回来源
- [ ] 年份/人名/地名拼写正确
- [ ] 引语不是编造的；转述不加引号
- [ ] 没有把相关性说成因果
- [ ] 没有医疗/投资建议式表述
- [ ] 真实人物照片有授权；没有 AI 生成真人脸
- [ ] 地图边界表述谨慎，使用有许可的数据
- [ ] 音乐/音效/字体/图片许可已记录
- [ ] 需要时加了「科普，不构成投资/医疗建议」声明

## 7. 声音（有音轨时）

- [ ] 人声清晰，没有被音乐盖住
- [ ] 音乐在 −14 LUFS 左右
- [ ] 数字/专有名词读音正确
- [ ] 结尾有淡出，不突然截断
- [ ] 没有版权不明的音乐
- [ ] 字幕与语音同步

## 8. 交付

- [ ] `output/<slug>.mp4`
- [ ] `output/<slug>.srt`
- [ ] `output/stills/` 关键帧
- [ ] `sources.md` / `notes.md` 更新
- [ ] 封面导出
- [ ] 发布包（标题/简介/标签/置顶评论）
- [ ] 文件名符合规范

## 9. 教程里的踩坑清单

- [ ] 3D 文字没有用 three.js 自带字体（中文会变方块）
- [ ] 字体放在项目内，用 `@font-face` 加载，等字体加载完再渲染
- [ ] 上万粒子用 `InstancedMesh` / `Points`，没有逐个 Mesh
- [ ] 地球/地图用真实海陆轮廓数据（Natural Earth GeoJSON）
- [ ] 二维码用 `qrcode` 库生成真实可扫的码（如果用到）
- [ ] 长片分段渲染，出错不用从头再来
- [ ] 渲染前先导 5–10 秒小段检查
- [ ] 没有把无声预览说成「已配音成片」

## 10. 最后一眼

- [ ] 如果我是刷到这条视频的陌生人，前 3 秒会停下来吗？
- [ ] 中间有没有哪 10 秒我想划走？
- [ ] 结尾那句话，我愿意转发吗？
- [ ] 评论区最可能质疑什么？我能贴出来源吗？
