# 02 · 选题与大纲

## 1. 什么样的科普选题能爆

不是「知识量大」，而是同时命中下面几条：

| 要素 | 说明 | 例子（结构，不是原题） |
|---|---|---|
| 好奇缺口 | 观众以为自己知道，但发现不知道 | 「一天其实不是 24 小时」 |
| 具体数字 | 越具体越可信，越想知道为什么 | 「0.07 秒」「140 万公里」「8 年」 |
| 熟悉动作 | 从观众每天都在做的事切入 | 发照片、扫码、刷视频、买菜 |
| 身份代入 | 让观众觉得「说的就是我」 | 「凌晨 1 点，再刷最后一条」 |
| 可视化 | 每段都有一个看得见的动作 | 光穿过光纤、图表生长、时间轴推进 |
| 情绪落点 | 结尾能让人「原来如此」或被打动 | 「正因为被困住，光才把世界连在一起」 |

**一句话测试**：如果不能用一句带数字或反常识的话说清楚，就还没想好。

**三镜头测试**：在纸上画不出开头、中段、结尾三个画面，说明视觉化程度不够，换题或换角度。

## 2. 三个方向的不同打法

### 历史

- 核心不是「年份流水账」，而是 **因果链 + 证据 + 人**。
- 每讲一个事件，回答：为什么是这里、为什么是这个时候、为什么是他们。
- 视觉锚点：地图、时间轴、剖面、档案纸、旧照片、路线。
- 常用结构：一个「不可能」的结果 → 拆开条件 → 关键人物/决定 → 代价与遗产。
- 风险：数字和年代版本多；用保守说法，来源写进 `sources.md`。

### 科学

- 核心是 **反直觉 + 原理拆解 + 尺度感**。
- 先给生活例子，再给专业词；每一步「前一步的结果变成下一步的开头」。
- 视觉锚点：光、粒子、剖面、轨道、波形、尺度对比、公式变形。
- 常用结构：一个日常现象 → 你以为的解释 → 真正的机制（3–5 步）→ 尺度放大 → 一句人话总结。
- 风险：不要把「假说」讲成「定论」；医学、健康类用保守表述。

### 投资

- 核心是 **钱 + 时间 + 风险 + 人的行为**。
- 最有效的三种爽点：算一笔账、看一条曲线、发现一个心理偏差。
- 视觉锚点：图表生长、复利曲线、购买力、时间轴、对比条、账户界面。
- 常用结构：一个日常决策 → 算账 → 反常识结论 → 行为陷阱 → 可执行的一条建议。
- 风险：不做投资建议；数据注明来源和日期；相关性不说成因果。

## 3. 五幕结构（2–2.5 分钟）

| 段落 | 建议时长 | 作用 | 必须回答 |
|---|---|---|---|
| 钩子 | 0–15s | 让人停手 | 反常识问题/数字是什么？ |
| 进入世界 | 15–40s | 把观众放进场景 | 全片跟着谁/什么走？ |
| 原理拆解 | 40–90s | 核心奇观 | 3–5 步，每一步画面都变 |
| 人的故事/类比 | 90–110s | 情绪缓冲 | 谁在为这件事付出？ |
| 回收与升华 | 110–140s | 答案落地 | 开头那个数字/问题怎么回收？ |

> 教程里的四条爆款基本都符合这个骨架：钩子 → 进入 → 原理/实验 → 人物/算账 → 回收 → 金句。结构可以复用，题材要换成自己的。

## 4. 钩子的六种写法

1. **具体到小数点的数字**：「0.07 秒」「8 分 20 秒」「37.8 倍」。
2. **反常识问题**：「二维码会被用完吗？」「一天真的是 24 小时吗？」
3. **熟悉动作 + 陌生解释**：「你每天都在扫码，却从没想过它怎么来的。」
4. **身份代入**：「凌晨 1 点，你对自己说再刷最后一条。」
5. **尺度对比**：「把地球缩成一粒米，太阳有多大？」
6. **代价/损失**：「不用花钱，你的钱也在变少。」

钩子必须出现在 **前 3 秒**，而且第 1 帧就要有完整画面，不要从黑场淡入。

## 6. 十分钟快筛

在正式立项前，用 10 分钟做四件事：

1. 搜 3 个可靠来源（论文/政府/权威机构/博物馆），能找齐 → 可做；
2. 找出 3 个能上画面的数字/对比 → 可视化够；
3. 在纸上画 3 个镜头（开头/中段/结尾）→ 有视觉主角；
4. 写出结尾金句 → 有情绪落点。

四件事有一件做不顺，先换角度，不要急着写代码。

## 7. 常见死法

- **太抽象**：全片都是概念，没有物体、动作、尺度。
- **没有具体数字**：只有「很多」「很久」「很大」，观众没有记忆点。
- **一个镜头讲不完**：2–3 分钟塞了 5 个主题，每个都浅。
- **开头讲背景**：前 15 秒都在「自古以来」，观众已经划走。
- **结尾说教**：最后 20 秒变成鸡汤，没有回收前面的钩子。
- **事实不可核查**：数字来源不明，评论区一质疑就崩。
