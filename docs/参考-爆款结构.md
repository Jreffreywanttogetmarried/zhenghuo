## 3. 四条样片的共同点

1. **开头 3 秒有钩子**：熟悉动作、反常识问题、具体数字，三者至少占一个。
2. **全片有一个视觉主角**：一束光、一个二维码、一只鸽子、一个小人。所有镜头跟着它走，不跑题。
3. **每 3–8 秒有一个画面变化**：镜头动、物体动、数字跳、颜色变。
4. **中段有一个人**：高锟、原昌宏、斯金纳、下拉刷新发明者。人物用来缓一口气，也让知识有温度。
5. **算一笔账**：把数字换算成观众能感知的尺度（绕地球 35 圈、一辈子 8 年、宇宙重来 250 万亿次）。
6. **结尾回收开头**：0.0700 秒、回到围棋、鸽子没得选但你有、16 张卡片全部点亮。
7. **金句短、可转发**：一句话，最多两行，带一个金色关键词。

## 4. 不要照搬

- 不要直接搬运教程里的四个题材；换自己的选题。
- 不要照抄提示词里的数字；所有数字重新查证。
- 不要复制教程里的具体画面/角色/配色；借用的是结构，不是素材。
- 不要用教程里的「真人照片」；除非你有授权，否则用剪影。
- 教程是本地资料，不要公开分发原文。

## 5. 一句话总结

> 爆款不是「知识多」，而是：**一个熟悉的钩子 + 一个能跟着走的主角 + 每几秒一个变化 + 一笔算得清的账 + 一句能被转述的话。**
