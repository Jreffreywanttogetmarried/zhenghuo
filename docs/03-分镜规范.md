# 03 · 分镜规范

## 1. 分镜表是什么

分镜表是「大纲」和「代码」之间的合同。它必须细到每一行都能直接变成一个场景或一段动画：

- 这一镜从第几秒到第几秒；
- 画面里有什么主体、在做什么；
- 镜头怎么运动；
- 字幕是什么（【】= 金色高亮）；
- 怎么转场；
- 有没有声音/音效。

## 2. 字段

| 字段 | 要求 |
|---|---|
| 镜号 | 01、02…… 与场景文件对应 |
| 入点/出点 | `0:00.0` 格式，精确到 0.1 秒 |
| 时长 | 秒；30fps 下 1 秒 = 30 帧 |
| 场景/段落 | 钩子 / 进入 / 原理 / 人的故事 / 回收 / 升华 |
| 画面内容 | 主体 + 动作 + 变化，不要只写「讲原理」 |
| 镜头运动 | 推、拉、摇、环绕、俯冲、贴地平移、锁定 |
| 字幕 | 按每秒 6–7 个字写；【】包住关键词 |
| 转场 | 硬切 / 穿过 / 变形 / 遮挡 / 匹配剪辑 |
| 声音/备注 | 音乐、音效、需要查证的数字 |

## 3. 硬规则

### 字幕

- 普通字幕 **64px**，白色，字间距 2px，居中，默认距顶部约 **690px**，最多两行。
- 关键词用【】标出，显示为金色 `#FFC15E`，略微加粗。
- 每句停留 **2–3 秒**；按 **每秒 6–7 个字** 计算。
- 字幕不能挡主体：主体在下方时，字幕移到上方（距顶部约 110px）。
- 进场 7 帧淡入 + 上浮 12px；出场 7 帧淡出。

### 画面

- 每一句字幕都必须对应一个看得见的画面变化（镜头动、物体动、数字跳、颜色变）。
- 不能出现「字在换、画面不动」超过 **3 秒**。
- 镜头永远在缓慢运动，速度用 `easeInOut`，不能匀速、不能抖。
- 开头 3 秒内出现钩子；第 1 帧画面完整，不从黑场淡入。
- 数字出现时滚动计数 **20–40 帧**，停下时轻微放大回弹。

### 转场

- 优先「镜头穿过去」「物体变形」「遮挡擦除」「匹配剪辑」。
- 少用淡入淡出黑场；不要用随机的炫光转场。
- 硬切要有理由：视角切换、时间跳转、风格对照。

## 4. 时间码换算（30fps）

| 秒 | 帧 |
|---|---|
| 0.5 | 15 |
| 1 | 30 |
| 2 | 60 |
| 3 | 90 |
| 5 | 150 |
| 10 | 300 |
| 15 | 450 |
| 30 | 900 |
| 60 | 1800 |
| 120 | 3600 |

- 7 帧淡入 ≈ 0.233 秒。
- 一句 14 个字的字幕，按 6.5 字/秒 ≈ 2.15 秒 → 留 2.2–2.6 秒。
- 2 分钟片 = 120 秒 = 3600 帧。

## 5. 镜头语法

| 运动 | 表达 | 适合 |
|---|---|---|
| 缓慢推近 | 聚焦、压迫、进入 | 钩子、名词卡、结尾 |
| 缓慢拉远 | 释放、尺度、全貌 | 从个体到系统、结尾 |
| 环绕 | 展示立体主体 | 地球、光缆、文物 |
| 贴地/贴水平移 | 陪伴、旅程 | 海底、隧道、时间轴 |
| 俯冲 | 进入新世界 | 从太空到海面、从地图到细节 |
| 锁定 | 变化本身是运动 | 图表生长、数字跳动 |
| 快速甩镜 | 惊讶、转折 | 反转、算账前 |

> 一个镜头只讲一件事。镜头运动要服务内容，不要为了动而动。

## 6. 分镜 → 代码的映射

一期 episode 的结构：

```json
{
  "scenes": [
    { "id": "hook", "module": "scenes/01-hook.js", "start": 0, "duration": 15 },
    { "id": "world", "module": "scenes/02-world.js", "start": 15, "duration": 25 }
  ],
  "subtitles": [
    { "start": 0.4, "end": 3.2, "text": "你在上海，给朋友发了一张照片" }
  ]
}
```

- `scenes[].start/duration` 必须和分镜表的入点/出点一致。
- `subtitles[].start/end` 必须和分镜表字幕列一致。
- 一个场景文件只负责一个段落；场景内部的镜头变化用 `t` 计算。
- 场景之间默认硬切；如果分镜写了「穿过」，在场景代码里做连续运动，而不是靠引擎转场。

## 8. 分镜阶段的自检

- [ ] 开头 3 秒有钩子
- [ ] 每句字幕都有画面变化
- [ ] 没有超过 3 秒的静止画面
- [ ] 字幕不超过两行，不挡主体
- [ ] 至少有一个「奇观段」（值得截图的画面）
- [ ] 结尾回收了开头的钩子
- [ ] 所有数字都能在 `sources.md` 找到
- [ ] 总时长与 `episode.json` 一致
