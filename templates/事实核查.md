## 3. 引语核查

| 引语 | 说话人 | 原始出处 | 是转述还是原话 | 是否可用 |
|---|---|---|---|---|
| | | | | |

- 找不到原始出处的引语：改成转述，不加引号。
- 不要把「据说」「网上说」写成事实。

## 4. 图片/音频/字体许可

| 素材 | 作者/机构 | 许可 | 来源链接 | 画面标注 |
|---|---|---|---|---|
| | | | | |

- 真实人物照片：只用可商用授权（如维基共享资源 CC），角落标注来源。
- 找不到授权照片：用剪影，不用 AI 生成真人的脸。
- 地图：使用有明确许可的边界数据（如 Natural Earth），注意边界表述。
