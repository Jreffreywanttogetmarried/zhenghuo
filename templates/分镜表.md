# 分镜表模板

> 分镜表是「大纲」和「代码」之间的合同。每一行必须能直接变成一个场景或一段动画。
> 先写满时间码和字幕，再写画面；不要反过来。

## 1. 全片参数

- 总时长：____ 秒（30fps = ____ 帧）
- 画幅：1920×1080
- 字幕：每秒 6–7 个字；单句 2–3 秒；最多两行；【】= 金色高亮
- 画面：同一画面不超过 3 秒无变化；镜头始终缓慢运动
- 转场：优先「镜头穿过去 / 物体变形」，少用淡入淡出黑场

## 4. 校验

- [ ] 场景起止时间与 `episode.json` 的 `scenes` 一致
- [ ] 字幕起止时间与 `episode.json` 的 `subtitles` 一致
- [ ] 每个场景至少有一句字幕/旁白
- [ ] 开头 3 秒内出现钩子
- [ ] 没有超过 3 秒的静止画面
- [ ] 每个关键数字都能在 `sources.md` 找到来源
- [ ] 字幕不挡主体；主体在下方时字幕移到上方（y≈110）
