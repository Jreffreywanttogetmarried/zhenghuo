# 000 风格测试片 · 制作笔记

## 目的

一次性验证三件事：

1. 浏览器动画引擎的 `window.renderAt(t)` 时间接口是否稳定；
2. 三种科普方向的视觉预设是否能形成明显区分；
3. 字幕、关键词高亮、数字滚动、图表生长、时间线是否达到教程规范。

## 结构

| 时间 | 段落 | 视觉语法 | 风格参考 |
|---|---|---|---|
| 0–4s | 历史 | 羊皮纸舞台 + 时间轴生长 + 节点弹入 | M20 时间线/历史 · K35 旧学院风 |
| 4–8s | 科学 | 深蓝实验室 + 光脉冲沿贝塞尔轨迹飞行 + 光速滚动 | M18 科学讲解 · M21 原理拆解 |
| 8–12s | 投资 | 奶油纸卡 + 柱状图生长 + 复利大数字 | L40 数据叙事 · F1 图表生长 |

## 预览与渲染

```bash
# 在项目根目录预览（浏览器打开 http://localhost:8080/episodes/000-style-test/）
python -m http.server 8080

# 渲染全片
python tools/render_video.py episodes/000-style-test --output episodes/000-style-test/output/000-style-test.mp4
```
