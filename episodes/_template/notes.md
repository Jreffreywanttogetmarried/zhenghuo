## 声音

- 默认：无配音、无 BGM，字幕即旁白。
- 如果加 BGM：
  - 文件放到 `assets/audio/`；
  - 在 `episode.json` 填 `audio`：
    ```json
    "audio": {
      "src": "assets/audio/bgm/你的音乐.mp3",
      "bpm": 120,
      "offset": 0,
      "loop": true,
      "volume": 0.9,
      "fadeOut": 2
    }
    ```
  - 卡点：用 `python tools/beat_grid.py --bpm 120 --offset 0 --duration <秒> --every 8` 生成拍点表，把场景切点放在拍点上。
  - 场景里用 `env.beat.pulse(env.globalT)` 做节拍脉冲（详见 `AI视频制作手册.md` 的 BGM + 卡点一节）。
